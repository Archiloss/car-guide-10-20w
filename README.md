# 10–30 万家用新能源车清单 · 湖北十堰

给 2–4 人家庭做的选车参考：后排坐得下 2 个成年人、婴儿车和行李能一起装、冬天在湖北不用续航焦虑。

- 41 款在售新能源车里选出推荐 20 款：四条价格带（10-15 / 15-20 / 20-25 / 25-30 万）**各 5 款**
- 综合分 = 安全 30% + 续航 25% + 家庭适配 15% + 保值 15% + 性价比 15%
- 每款车的关键指标都标了口径（谁测的、什么温度、什么工况），查不到就写「未查到」
- 政策部分只讲「能省多少、怎么办」，法规条文原文不放在页面上
